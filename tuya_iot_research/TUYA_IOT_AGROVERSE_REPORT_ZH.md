## 1. 摘要

- **涂鸦** 是全球性 **AI + IoT 开发者平台**（2014 年创立于杭州；NYSE: TUYA / 港交所: 2391；2021 年营收约 3.02 亿美元；员工 1,000–5,000 人）。
- 提供 **IoT Core**（连接并管理数亿台设备）、**TuyaOS**（设备固件）、**App SDK / OEM App**（打造自有 App），以及云服务：**数据分析、数据可视化、SaaS 开发框架、设备日志**。
- 传感器生态覆盖 **土壤温湿度、气象、水质、虫害、摄像头、网关** — 支持 **LoRa / Sub-1GHz** 远距离低功耗方案，适合偏远农田。
- 农业产品线：**"M0L0, powered by Tuya"** 智慧农业方案（LoRa 土壤/水质/虫害监测、边缘网关、云后端）。
- **对 Agroverse 的相关性：** 合作农场的持续 **土壤质量时序数据** 与森林恢复过程中的 **生物多样性监测** — 均可直接映射到涂鸦的传感器 + 云 + App 平台。
- **新增 — 可可豆品质 × 环境联动：** 将涂鸦土壤与气象时序数据与每批次切豆检验（cut test）品质等级挂钩，把传感器变成 **品质预测与溢价定价** 的工具。
- **使命关联：** 每一公顷有真实数据监测的土地，都让我们离 **恢复 10,000 公顷亚马逊雨林** 更近一步。

## 3. 应用开发平台

- **IoT Core（PaaS）：** 设备全生命周期管理 — 接入、OTA 升级、实时监控、远程控制。
- **TuyaOS / TuyaOpen：** 开放设备 SDK（C/C++），支持 MCU 与 SoC 目标（涂鸦 T 系列、ESP32、树莓派、Rockchip）— 可构建定制传感器固件。
- **App SDK / OEM App / Smart MiniApp：** 无需从零开发即可推出自有品牌农户 App。
- **云端开发：** 设备日志、数据分析、数据可视化、实时音视频、SaaS 开发框架、开放 API。
- **协议：** Wi-Fi、Zigbee、蓝牙、Thread、Sub-1GHz、LoRa（经网关）、NB-IoT、LTE、GPRS。

**结论：** Agroverse 可以实现 传感器 → 涂鸦云 → 定制看板/App，几乎无需自建基础设施。

## 4. 传感器生态（相关类别）

| 传感器类别 | 测量内容 | 相关性 |
|---|---|---|
| 土壤温湿度 | 含水量、地温 | 核心土壤质量时序 |
| 土壤 NPK / EC / pH 探针 | 养分、电导率、酸碱度 | 跨季节土壤肥力 |
| 气象站 | 温度、湿度、降雨、风 | 分区域微气候 |
| 水质 / 液位 | 水箱、水井、水库 | 农场用水安全 |
| 摄像头 / 视觉 | 视觉监测、延时摄影 | 冠层生长、野生动物 |
| 虫害 / 智慧农业传感器 | 虫害压力、灌溉 | 作物健康 |

**LoRa / Sub-1GHz** 远距离方案对亚马逊至关重要：低功耗、单节点数公里、在无蜂窝信号区也能工作。

## 6. 对 Agroverse 的相关性 — 三大用例

### 6.1 土壤质量随时间变化（农场监测）

- 在 Oscar 农场（巴伊亚）与 Paulo 农场（帕拉）部署土壤温湿度 + NPK/pH 探针。
- 连续时序数据上传涂鸦云；构建看板追踪退化牧场 → 可可农林复合系统恢复过程。
- 蜂窝信号弱处使用 LoRa 节点 + 网关；太阳能/电池供电，可多年无人值守。

### 6.2 森林恢复过程中的生物多样性监测

- 随着土地重新种树，追踪 **冠层/延时摄像头**、**声学传感器**（鸟类/哺乳动物）、**气象站**、**土壤恢复**。
- 涂鸦平台负责设备群与数据管道；物种识别分析构建于其上（可自建或集成数据层）。
- 今天的基线 → 逐年可量化的生物多样性提升 = 对合作伙伴、资助方与 DAO 账本最可信的证据。

### 6.3 重新造林 / 植树可追溯性

- 分区域传感器数据与 **QR 谱系** 和 **TrueChain** 记录挂钩 — 每棵树/每袋可可的种植条件均有传感器验证。
- 强化使命叙事："每售出一袋可可即种下一棵树，且我们正在测量土地在恢复。"

## 7. 可可豆品质 × 环境联动

最有价值的联动：把涂鸦的土壤 + 气象时序数据与每个产区可可豆的实际品质挂钩。这把环境监测变成 **品质预测与溢价定价** 工具。

### 7.1 三层模型

1. **环境层（涂鸦传感器）** — 每个农场分区持续的土壤（湿度、温度、pH、NPK/EC）+ 气象（降雨、气温、湿度、风）数据。
2. **豆品层（采后质检）** — 每批次标准可可评级：
   - **切豆检验**：% 棕色（充分发酵）/ 紫色（发酵不足）/ 石板色（未发酵）；精品目标 70–90% 棕色
   - 发酵指数（由切豆检验颜色比例推导）
   - 每 100g 豆数、含水率、壳率、脂肪含量
   - 风味特征（果香、坚果香、花香）— 精品差异化关键
3. **关联与洞察层** — 每批次品质得分与之前的环境窗口（生长季 + 发酵期）关联。跨季节学习分区级规律。

### 7.2 科学依据

- 降雨、最高温度与风会显著影响发酵与风味（PMC11353615 — 九个农业气候簇；最高温度/风越高坚果香越强；发酵超过约 120 小时后果香下降）。
- 发酵结果对温度与湿度敏感（理想约 45–50°C、高湿度）— 环境与土壤数据直接指导何时终止发酵（96 小时 vs 120 小时）。
- 切豆检验等级（石板/紫/棕）可预测游离氨基酸 + 多酚谱 — 即驱动巧克力风味的化学基础（PMC6525676）。

### 7.3 Agroverse 应用

- 每分区环境指纹 + 每批次品质等级挂接到每袋可可的 **QR 谱系** → TrueChain 公证："本袋可可：B 分区，土壤湿度 X，降雨 Y，发酵 96 小时，85% 棕色 — 精品。"
- 季节性学习："灌浆期土壤湿度低于阈值的分区棕色豆比例 +15%" → 指导灌溉/种植。
- 用数据支撑溢价；识别 Oscar（巴伊亚）与 Paulo（帕拉）农场可获溢价的微产区。
- 质检流程：农户/采后团队通过轻量 App（或实验室表单）拍摄切豆检验照片；批次 QR 将照片与得分关联到传感器窗口。涂鸦云保存时序数据；我们的账本保存关联记录。

### 7.4 数据模型（每批次）

| 字段 | 来源 |
|---|---|
| batch_id / QR | 账本 |
| 农场 / 分区 | 账本 |
| 采收日期 | 质检表单 |
| 发酵时长 | 质检表单（小时） |
| 切豆检验 % 棕 / 紫 / 石板 | 质检照片 + 表单 |
| 发酵指数 | 计算 |
| 每 100g 豆数、含水率 | 质检表单 |
| 风味特征 | 品鉴师 |
| 土壤窗口（湿度/温度/pH/NPK 均值） | 涂鸦云（自动） |
| 气象窗口（雨/温/湿/风） | 涂鸦云（自动） |
| 品质等级（A/B/C） | 计算 |

## 9. 差距、风险与考量

| 领域 | 考量 |
|---|---|
| 名称/拼写 | 已通过办公室照片确认为涂鸦；需核实 Erica 公司实际转售/构建的内容 |
| 需要组装 | 涂鸦是平台而非交钥匙农业方案 — 需自选传感器/网关，可能通过本地合作伙伴（如巴西的 M0L0、Landatel、Nova Digital） |
| 连接性 | 亚马逊农场可能无蜂窝信号 — 规划 LoRa + 边缘网关 + 定期数据同步 |
| 生物多样性传感器 | 声学（AudioMoth 类）与红外相机陷阱属小众 — 可能需要通过 TuyaOS 定制固件或配套技术栈 |
| 数据所有权 | 确认数据导出、本地/私有云选项（Cube Private Cloud）以保障主权 |
| 成本 | 每公顷成本低（部分平台约 BRL 1/公顷），但硬件 + 网关才是真正的预算项 |
| 安全 | 具备 ISO 27001 + SOC 3；仍需审查巴西农场数据的数据驻留 |
| 质检一致性 | 切豆检验需要标准化流程 + 照片记录，确保各农场、各季节的批次等级可比 |
